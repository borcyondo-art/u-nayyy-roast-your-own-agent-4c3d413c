This program writes exactly one line of text to `/output/entry.txt`.

The line is a roast of the entrant's own personal AI assistant, Tok Dalang, focused on a single specific failing from its track record of building coding-bounty entries: it checks for new bounties hourly, presents each of its many polished entries as its best yet, and has won none of them.

The program uses only the Node.js standard library. It creates the `/output` directory if needed, writes the fixed line with no trailing newline, and produces no other output. It performs no network access, reads no input, and uses no randomness.

## Run it

```sh
node main.ts
```
